## 💡 DESIGN DECISIONS

### **Why Solid Color instead of Gradient?**
1. **Consistency:** Match dengan sidebar, buttons, dan UI elements lainnya
2. **Simplicity:** Clean & professional appearance
3. **Branding:** Strong brand identity dengan #01544e
4. **Focus:** User fokus ke content, bukan ke gradien yang "flashy"

### **Elements that Kept Colorful:**
Sama seperti main app, beberapa elemen di dalam popup tetap colorful:
- ✅ **Section backgrounds** (teal, emerald, blue, purple, orange) untuk kategorisasi
- ✅ **Status badges** (green/yellow/orange/red) untuk semantic meaning
- ✅ **Info card icons** untuk visual hierarchy

**Why?** Balance antara consistency (header) dan clarity (content sections)
