## 📊 TECHNICAL ARCHITECTURE

### Component Structure

```
KPIAIEnhanced/
├── State Management
│   ├── targets[] (KPI data)
│   ├── employees[] (user data)
│   ├── viewMode (analytics/grid/list)
│   ├── aiChatOpen (dialog state)
│   └── chatMessages[] (conversation history)
│
├── AI Functions
│   ├── generateAIInsights()
│   ├── generateAIRecommendations()
│   ├── generateAIPredictions()
│   ├── generateAIAlerts()
│   └── handleAIChat()
│
├── Helper Functions
│   ├── calculateProgress()
│   ├── calculateOverallProgress()
│   ├── getProgressColor()
│   ├── getProgressBadge()
│   └── formatCurrency()
│
└── UI Components
    ├── View Mode Tabs
    ├── Analytics Tabs
    ├── AI Chat Dialog
    ├── Target Form Modal
    └── Progress Cards
```

### Data Flow

```
1. Data Fetch
   employeesApi.getAll() → Filter sales employees

2. Mock Generation
   generateMockTargets() → Create KPI data

3. AI Processing (per employee)
   ├── generateAIInsights() → Natural language analysis
   ├── generateAIRecommendations() → Prioritized actions
   ├── generateAIPredictions() → Forecasts
   └── generateAIAlerts() → Anomaly detection

4. Render
   View Mode → Tabs → Cards → Data visualization

5. Interaction
   User input → AI Chat → handleAIChat() → Response
```
