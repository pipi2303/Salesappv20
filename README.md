# Sales Monitoring Pro - PWA

Aplikasi web-based untuk monitoring sales yang lengkap, modern, dan interaktif dengan fitur PWA (Progressive Web App).

## 🚀 Fitur Utama

### 1. **Home Dashboard**
- Overview statistik sales real-time
- Grafik trend penjualan
- Analisis sumber leads
- Performance comparison tim
- Aktivitas terbaru

### 2. **Lead Management**
- CRUD lengkap untuk manajemen leads
- Filter berdasarkan status
- Voice input di setiap field
- Track kontak dan notes
- Status pipeline yang jelas

### 3. **Sales Tim**
- Monitoring performa tim sales
- Target vs achievement tracking
- Informasi detail setiap sales person
- Multiple view (Grid, List, Performance)
- Top performer highlight

### 4. **Product Catalog**
- Katalog produk & layanan lengkap
- Filter berdasarkan kategori
- Detail produk dengan fitur
- Best seller tracking
- Quick add to proposal

### 5. **Demo Scheduler**
- Penjadwalan demo produk
- Calendar view
- Join meeting langsung
- Status tracking (Scheduled, Completed, dll)
- Notes & reminder

### 6. **Contract Management**
- Kelola semua kontrak
- Status tracking lengkap
- Download kontrak
- Timeline monitoring
- Value tracking

### 7. **Sales Reports**
- Dashboard analytics lengkap
- Multiple report tabs:
  - Overview
  - Sales Analysis
  - Team Performance
  - Product Analysis
  - Regional Analysis
- Export to PDF
- Interactive charts & graphs

### 8. **Admin System**
Dengan 3 tab menu:
- **User Management**: Kelola users dengan role-based access
- **Roles & Permissions**: Matrix permissions lengkap
- **Audit Trail & Activity Log**: Track semua aktivitas sistem

## 🎓 User Guide

1. **Install PWA**: Klik tombol "Install App" di header
2. **Navigate**: Gunakan sidebar untuk berpindah menu
3. **Voice Input**: Klik icon mic biru untuk voice input
4. **AI Assistant**: Klik icon bot di pojok kanan bawah
5. **Add Data**: Gunakan tombol "Tambah" di setiap modul
6. **Filter**: Gunakan search & filter di setiap list
